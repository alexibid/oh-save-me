## Typography

### Font Families

The application uses different font families for specific contexts:
- **Brand:** `Nunito`
- **UI & Controls:** `DM Sans`
- **Sans-Serif (Data/Text):** `Inter`
- **Editorial (Headings/Quotes):** `Playfair Display`

### Font Weights

- **Regular:** `400`
- **Medium:** `500`
- **Semi-Bold:** `600`
- **Bold:** `700`

### Typescale

- **Body:** `15px` (`--text-body`)
- **Label:** `16px` (`--text-label`)
- **Title:** `28px` (`--text-title`)
- **Number:** `32px` (`--text-number`)

## Spacing & Layout

Consistent spacing scale for margins and paddings:

- `--space-2`: `8px`
- `--space-3`: `12px`
- `--space-4`: `16px`
- `--space-5`: `20px`
- `--space-6`: `24px`
- `--space-8`: `32px`

## Border Radius

Specific border radii values for different UI elements:

- **Control:** `10px` (`--radius-control`)
- **Balloon:** `12px` (`--radius-balloon`)
- **Card:** `16px` (`--radius-card`)
- **Pill:** `20px` (`--radius-pill`)
